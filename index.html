INST377 HTTP Lab

A tiny products API for practicing GET, POST, PUT, PATCH and DELETE. Changes are saved, so you can create something and then read it back.

Endpoints

Base URL:

MethodPathWhat it doesSuccess code
GET/api/productsList all products. Filter with ?name=Tim or ?productName=mug200
POST/api/productsCreate a product (all 4 fields required)201
GET/api/products/:idGet one product200
PUT/api/products/:idReplace the whole product (all 4 fields required)200
PATCH/api/products/:idChange only the fields you send200
DELETE/api/products/:idDelete the product204
ANY/api/echoSends back the method, query string, headers and body it received200

Product fields: name (your name), productName, productDescription, productPrice (number). Errors you can trigger on purpose: 400 (missing field), 404 (bad id), 405 (wrong method).
